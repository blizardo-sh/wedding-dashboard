# Модель данных

Версия пакета: `2.0`. Закрытые данные отделены от публичного приложения.

| Сущность         | Содержимое                                                                                                    | Где хранится                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| House            | Стабильный ID предварительной группы, заголовок, отдельные предложения, состояние связи                       | Каталог                       |
| Offering         | ID сайта, URL, характеристики, цена объявления, правила, фото, текст для поиска, происхождение                | Каталог + полная запись       |
| Feature claim    | `true / false / null`, цитата, признак конфликта; сезонность отдельно                                         | Полная запись                 |
| Price rule       | Тип, сумма, единица, период, порог гостей, применимость по дням, цитата, уровень проверки, неоднозначность    | Предложение                   |
| Scenario         | Заезд/выезд, гости по дням, ночующие, дети, услуги, количества за заезд, люди для оплаты услуг                | На устройстве                 |
| Decision         | Избранное, статус, заметка, выбранное объявление, связи, `confirmations` и `termsByOffering` по ID объявления | Отдельно от каталога          |
| History event    | Автор, время, ревизия, изменения и полный снимок решения после записи                                         | Неизменяемая история          |
| Member           | Google-email как ID, роль, активность                                                                         | Закрытая коллекция участников |
| Catalog manifest | Опубликованная версия и число групп/объявлений                                                                | `runtime/catalog`             |

В локальном пакете `catalog.json` содержит компактные группы. `details/{offeringId}.json` содержит полный текст, доказательства извлечённых характеристик, все фото и SHA-256 описания. `cloud-import.json` объединяет каталог с полными записями для управляемого импорта.

Firestore хранит каталог частями `catalogVersions/{version}/chunks/{id}` и описания в `catalogVersions/{version}/listings/{id}`. Части ограничены 650 КБ, полные записи — 800 КБ с запасом к лимиту документа. Тяжёлые массивы и тексты исключены из индексов. Новая версия становится текущей после завершения загрузки. Старые версии сохраняются; автоматического удаления исходных данных нет.

Ручные сведения хранятся в `decisions/{houseId}` и не участвуют в переимпорте. История каждой записи находится в `history/{eventId}` и связана транзакцией с текущей ревизией решения. Конкурирующие заметки проверяются перед записью, изменения карты уточнений защищены ожидаемой ревизией.

Уточнения одного источника не применяются к другому. Полная цена владельца привязана к каноническому ключу точного сценария. Смена дат, состава гостей или услуг отменяет её применение, исходный ответ остаётся в истории. Подтверждение цены и подтверждение свободных дат независимы.

Автоматические связи по коду объекта или идентичному описанию остаются предварительными. Ручное объединение не удаляет исходные решения: заметки связанных карточек, исходные ответы и история доступны из общей карточки. Разделение и обратное присоединение сохраняют все объявления.
